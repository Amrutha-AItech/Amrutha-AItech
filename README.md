### ⚡ LLM Cost & Latency Router

A backend-focused LLM routing system designed to explore intelligent model selection based on **cost, latency, and provider capabilities**.

The project is structured around provider abstraction and routing logic so that different LLM providers can be integrated without tightly coupling application logic to a single provider.

**Focus Areas:**
- LLM provider abstraction
- Model routing
- Cost-aware decisions
- Latency-aware decisions
- Provider fallbacks
- Mock providers for testing
- API testing
- Backend architecture
- Extensible provider design

**Tech Stack:** Python, FastAPI, LLM APIs, REST APIs, pytest

🔗 Repository: https://github.com/Amrutha-Altech/LLM-Cost-Latency-Router
